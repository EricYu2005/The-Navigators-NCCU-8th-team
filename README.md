# 💡 CareNav 智護領航：診間決策 Copilot × 家庭長照

歡迎來到本專案！這是一個專門為**團隊協作**打造的全端 Web 應用。
透過後端伺服器與輕量資料庫的串接，網頁擁有「**記憶功能**」，避開醫院封閉複雜的 HIS/EMR 系統，專注攻克「診間 150 秒溝通斷層」與「診後口頭醫囑流失」，所有資料在重新整理頁面或重啟電腦後都不會消失。

專案內建了 Windows 專屬的「一鍵式自動化工具（`.cmd`）」，讓即使不熟悉指令列的組員，也能輕鬆啟動、同步專案並保護機密資訊。

## 🧭 CareNav 原型系統四大核心頁面（左側面板導覽）

系統採用專業臨床級的**「左側導航選單」**，各功能獨立展示、不混在同一頁：

1. 🏠 **全家照護看板 (Family Care Hub)**：跨科看診時間軸、下次回診倒數計時、今日四時段服藥排程、手足協同備忘。
2. 📋 **診前臨床指引卡 (Doctor Discussion Guide)**：輸入近期表徵（晨起血壓、夜尿頻率、水腫），AI 自動濃縮為主治醫師 **20 秒快讀指引卡**，並附帶 **醫師 5 秒勾選回條**，支援友善列印或手機全螢幕展示。
3. 🎙️ **口頭醫囑結構化轉譯 (Verbal Orders Digitization)**：出診間後極速錄音或文字輸入醫師口語交代，自動解析為【觸發條件 - 具體行動 - 危急警訊】白話指引，同步推播全家。
4. 💊 **藥袋逆向推導引擎 (Prescription Inference Engine)**：拍照/上傳藥袋標籤，自動解析醫學用法代碼（QD AM/HS、BID），比對前後期處方異動（時段調整、新藥加入），並**預留藥學知識庫 MCP 介面**！
5. 🏥 **在地醫院 Hub 陪診媒合 (Hospital Hub)**：林口長庚、台大、榮總專屬護理特助媒合派案。

---

### 🚀 選項 [1]：一鍵全自動同步（推薦組員日常使用首選）
* **執行流程**：
  1. 自動從 GitHub 下載組員最新的代碼 (`git pull`)。
  2. **自動檢查相依套件**：若組員有新增 npm 套件，系統會自動在背景執行 `npm install`，絕不讓程式因缺少套件而崩潰！
  3. 列出您修改過的檔案，並提示輸入一句「本次修改說明」（若直接按 Enter 則代表僅拉取不推送）。
  4. **嚴格安全過濾**：自動將 `.env`、`secrets.vault`、`data.db` 剔除於提交名單之外，安全推送上傳至 GitHub！

---

### 📥 選項 [2]：僅拉取最新代碼 (Pull Only)
* **何時使用**：每天開始動工前、或組員在群組說「我傳了新功能，大家更新一下」時。
* **特色**：拉取後會自動執行 `npm install` 檢查，確保本地環境隨時就緒。

---

### 📤 選項 [3]：僅推送我的進度 (Push Only)
* **何時使用**：當您在本地完成了某個功能、美化了畫面，確認可以分享給組員時。
* **特色**：內建防呆過濾機制，絕不外流機密。

---

### 🔐 選項 [4]：機密資訊安全管理中心（★ 全組同步儲存機密的核心）

這是專為團隊共享金鑰打造的加密中心：

```text
================================================================
      🔐 機密資訊管理中心 (儲存、同步與加密保護)
================================================================
  [1] 📝 編輯本機 .env 設定檔 (使用記事本開啟)
  [2] 🔒 匯出加密機密包 (設定密碼，產生團隊分享密文字串)
  [3] 🔓 匯入團隊機密包 (貼上密文並輸入密碼，一秒同步 .env)
  [4] 📋 自動更新 .env.example 公開範本 (遮蔽數值後供 GitHub 參考)
  [0] 返回主選單
================================================================
```

#### 💡 情境範例：組長新增了 API Key / Ollama 模型，組員如何同步？

1. **組長端操作（匯出）**：
   - 雙擊 `sync.cmd` ➜ 選擇 `[4]` 進入機密中心 ➜ 選擇 `[2] 匯出加密機密包`。
   - 輸入一組團隊約定好的通關密碼（例如：`nccu-team8`）。
   - 系統會透過 **AES-256 演算法**，將本地的 `.env` 內容打包成一串加密文字（例如：`74b4218af...`）。
   - 組長把這串加密文字直接傳到 LINE / Discord 群組（因為經過密碼加密，即使公開在群組也無法被破解）。

2. **組員端操作（匯入同步）**：
   - 組員在群組中複製那段加密文字。
   - 雙擊 `sync.cmd` ➜ 選擇 `[4]` 進入機密中心 ➜ 選擇 `[3] 匯入團隊機密包`。
   - 貼上加密文字，輸入團隊密碼 `nccu-team8`。
   - **完成！** 系統瞬間解密，並自動把正確的設定寫入組員電腦中的 `.env`，全組設定完全一致！

3. **公開安全範本更新**：
   - 選擇 `[4]`，系統會自動去除真實密碼，將變數名稱更新至 `.env.example`，放心地隨 Git 上傳讓所有人參考。

---

### 🛠️ 選項 [5]：Git 衝突急救與狀態診斷
* 若同步過程中不幸遇到 Git 衝突、或出現 `index.lock` 報錯卡住時，執行此選項：
  - `[1] 取消目前的 Merge / Rebase 衝突`：瞬間重設回安全狀態。
  - `[2] 強制刪除卡住的 Git Lock 檔案`：修復因為異常關閉造成的鎖定。

## ❓ 常見問題排解 (FAQ)

**Q1：雙擊 `start.cmd` 提示找不到 Node.js？**
> 請至 [nodejs.org](https://nodejs.org/) 下載安裝 LTS 版本，安裝完成後請關閉所有終端機與資料夾，重新點擊 `start.cmd`。

**Q2：執行同步時被拒絕 (Rejected)？**
> 請直接在 `sync.cmd` 選 `[1]` 或 `[2]` 先拉取遠端最新進度，再執行推送。

**Q3：資料庫與機密會外洩嗎？**
> 絕對不會！本地資料庫 `data.db` 與機密 `.env` / `secrets.vault` 均已在 `.gitignore` 與 `sync.cmd` 雙層防護隔離。
