# 好選保健 PurePick

跨品牌保健品比較、重複去冗分析、服用日曆與看診清單管理平台  
政大創新創業入門第八組（The Navigators 團隊）專案作品

---

## 專案簡介

台灣保健食品市場普及率高，但消費端長期面臨「廣告促銷多、成分標籤繁雜、跨品牌盲目跟風購買」的問題。尤其針對 35 至 60 歲的青壯年與慢性病潛在族群，常同時購買多種不同品牌的保健品，容易引發「同質成分重複攝取」、「每日劑量超出安全上限（UL）」以及「看診時無法向醫師完整交代正在吃什麼」的真實困擾。

好選保健（PurePick）是一套針對行動裝置優化的 PWA（漸進式 Web 應用），免除繁瑣的 App 下載流程，透過直覺白話的生活語言、電商購物分享即時匯入、智慧成分防禦比對與日曆打卡，協助使用者：
1. 抓出多品牌重複購買與多花冤枉錢的成分。
2. 監控維生素與礦物質的每日安全上限，守護身體健康。
3. 建立服藥日曆，記錄體感狀態並生成動態升級建議。
4. 在看診時一鍵出示「告知醫生目前使用的保健品」清單卡片，弭平醫病溝通落差。

## 核心三大功能模組

### 1. 尋找：智慧需求分析與跨品牌方案推薦
- **生活化語言輸入**：不必記憶艱澀營養學名詞，輸入作息困擾（如長時間看螢幕、熬夜疲勞、外食少吃魚等）即可智慧解析。
- **保養重點與預算快篩**：提供晶亮護眼、循環代謝、精神體力、消化順暢、骨骼舒眠、氣色維持六大保養方向，搭配五段預算級距與飲食偏好（葷/素、吞膠囊難易度），即時生成最省錢且足量的產品組合。

### 2. 分析：考慮購買比對與重複去冗報告
- **跨品牌重複購買檢測**：比對魚油/Omega-3、葉黃素、維生素B群、維生素C/鋅、鈣鎂、益生菌等常見成分。
- **每日安全攝取上限（UL）警示**：一旦同類保健品加總超過衛生主管機關建議上限，即時標註高風險警告，避免過量負擔。
- **節省費用與每日開銷指標**：清楚列出每日平均保養花費，並估算剔除重複品項後每年可省下的金額。

### 3. 日曆：已購買保健櫃、服用打卡與看診輸出
- **服藥打卡與身體日誌**：提供月曆式打卡管理，追蹤每天吃過哪些保健品，並可記錄體力、腸胃、睡眠等身體感受。
- **每週健康總結與配方升級**：結合過去 7 日打卡與體感回饋，提供配方調整與 1 對 1 替換建議。
- **「告知醫生目前使用的保健品」一鍵輸出**：
  - 專為門診情境設計的高對比大字卡片。
  - 清楚列出目前所有已購買商品名稱、劑型、每日劑量與主要成分。
  - 支援全螢幕展示、一鍵友善列印、複製文字與 LINE 分享，讓主治醫師或藥師在 20 秒內完全掌握使用中的保健品。

## 手機版 PWA 與電商購物分享匯入

本專案支援現代 PWA（Progressive Web App）標準與 Web Share Target 規範：

- **免安裝商店，一鍵加入主畫面**：
  - iPhone（Safari）：點擊分享按鈕，選擇「加入主畫面」。
  - Android（Chrome）：點擊右上角選單，選擇「加到主畫面」或「安裝應用程式」。
- **電商購物分享即時匯入**：
  - 在 momo、蝦皮、屈臣氏、康是美或 iHerb 等購物 App 中，點擊商品頁的「分享」按鈕，選取「好選保健」，手機會自動開啟 App 並將商品寫入「已購買管理」清單。
  - 系統內建品類智慧過濾規則，若分享非保健品（如餅乾零食、日用品），會主動提示並排除，確保清單整潔。
- **LINE 快速登入與多層資料記憶**：
  - 整合 LINE 帳號登入，使用者資料依帳號獨立分區隔離。
  - 內建瀏覽器本地端備份與雲端自動同步機制，即使後端伺服器重啟或網路中斷，已購買與分析清單皆不會遺失。

## 團隊一鍵自動化工具（組員開發必看）

專案根目錄提供專屬的自動化批次工具，降低環境配置門檻：

| 工具腳本 | 主要功用 | 使用時機 |
| :--- | :--- | :--- |
| `start.cmd` | **一鍵啟動伺服器** | 日常開發、測試或報告演示時雙擊執行。自動檢查 Node.js、自動安裝套件、自動啟動伺服器並開啟瀏覽器。 |
| `sync.cmd` | **進度同步與機密管理** | 包含 Pull 最新程式碼、Push 本地成果、AES-256 加密同步 `.env` 金鑰，以及 Git 衝突急救修復。 |
| `gitignore.cmd` | **Git 規則防護** | 專案初始化或快取異常時執行，確保資料庫與機密檔案不被意外提交至 GitHub。 |

## 快速上手步驟

### 1. 環境需求
- 安裝 **Node.js (v18 或 v20 LTS 版本)**：[https://nodejs.org/](https://nodejs.org/)
- 安裝 **Git**：[https://git-scm.com/](https://git-scm.com/)

### 2. 下載專案 (Clone)
在終端機中執行：
```bash
git clone https://github.com/EricYu2005/The-Navigators-NCCU-8th-team.git
cd The-Navigators-NCCU-8th-team
```

### 3. 一鍵啟動
直接雙擊專案目錄下的 `start.cmd`：
1. 程式會自動檢查並補齊相依套件（`npm install`）。
2. 自動從 `.env.example` 建立本機 `.env` 設定檔。
3. 自動在瀏覽器開啟 `http://localhost:3000`。

亦可使用指令列啟動：
```bash
npm install
npm start
```

## 技術架構

- **後端環境**：Node.js + Express
- **資料庫存儲**：SQLite3（輕量單檔資料庫，依使用者 ID 分區，具備自動容災與本機持久化機制）
- **前端架構**：原生現代 Web 技術（Vanilla JavaScript、HTML5、現代 CSS、Service Worker）
- **視覺規範**：無 Emoji 干擾設計，全站採用高可視度灰色向量線條圖示（SVG），支援各尺寸手機與桌機響應式介面。
- **雲端部署相容**：相容於 Render、Railway、Heroku 等主流雲端 PaaS 平台，並提供啟動時資料庫自動初始化與靜態資產快取優化。

## 常見問題排解 (FAQ)

**Q1：執行 `start.cmd` 時提示找不到 Node.js？**  
請至 [nodejs.org](https://nodejs.org/) 下載安裝 LTS 版本，安裝完成後請關閉所有終端機與檔案總管視窗，重新執行 `start.cmd`。

**Q2：團隊如何同步機密 API Key 或環境變數？**  
雙擊 `sync.cmd` 進入選項 `[4] 機密資訊安全管理中心`，透過團隊約定密碼即可進行 AES-256 加密打包與一秒解密同步，無須在通訊軟體中明文傳送金鑰，更不會外洩至 GitHub。

**Q3：如何切換示範案例與全新空白帳號？**  
網頁右上角提供「示範案例 / 清空資料」切換按鈕；亦可直接點擊「LINE 登入」以真實個人身分使用，系統會嚴格區隔示範資料與個人專屬紀錄。
